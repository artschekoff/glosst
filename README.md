# Glosst

Расширение Chrome для чтения в оригинале. Курсор задержался на непонятном месте — появился перевод этого предложения и короткая пометка о том, что в нём легко понять неправильно.

Страница при этом не меняется: ни одного своего тега в чужой разметке. Расширение использует CSS Custom Highlight API для подсветки, поэтому сайты на React, Vue и других фреймворках продолжают работать как было.

## Установка

1. `chrome://extensions` → включить режим разработчика
2. «Загрузить распакованное» → папка этого репозитория
3. Открыть настройки расширения, вписать ключ OpenAI

## Настройки

Ключ, модель (по умолчанию `gpt-4o-mini`, можно вписать любую), язык перевода, режим (предложение или абзац), задержка курсора, срок хранения переводов, цвета подсветки, кнопка очистки кэша и сброса запомненных языков.

## Как устроено

- `src/content/` — всё, что касается страницы: наведение, нарезка, подсветка, тултип. Ключа API не видит и в сеть не ходит.
- `src/bg/` — кэш, настройки, обращение к модели.
- `src/options/` — страница настроек.

Переводы кэшируются по хэшу «текст + язык + модель», поэтому одна и та же фраза на разных страницах оплачивается один раз. Срок хранения — 30 дней, уборка раз в сутки.

В настройках две отдельные кнопки: одна очищает кэш переводов, другая сносит все запомненные языки по доменам. Первая экономит место, вторая полезна, если расширение неправильно определило язык страницы.

Если на странице нет атрибута `<html lang>`, расширение спрашивает язык один раз и запоминает выбор на этот домен. Это важно: неправильный язык может испортить разделение на предложения, поэтому угадывать нельзя.

## Тесты

```bash
npm test                    # чистые функции
npm run test:dom            # поведение в браузере
```

Первый набор — 76 тестов (1 пропущен по умолчанию, это живой вызов к OpenAI и стоит денег). Второй — 42 теста, все с Chromium.

Playwright установлен глобально на этой машине (в `~/.local`), а не в проекте, поэтому browser suite работает без дополнительной установки.

Чтобы запустить живой вызов (не требуется для разработки):
```bash
GLOSST_LIVE=1 OPENAI_API_KEY=sk-... npm test
```
